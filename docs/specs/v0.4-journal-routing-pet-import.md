# OpenClaw Pets v0.4 interaction specification

## Goals

This release adds editable Journal entries, conservative automatic speech
routing, local Petdex imports, and safe simultaneous use from multiple desktop
computers connected to one OpenClaw Gateway.

## Journal editing

- Every visible Journal observation can be edited, regardless of whether it
  originated from a desktop pet or another configured ingress such as voice.
- Editing changes only the text. Source, occurrence time, routing metadata, and
  interaction metadata remain intact.
- A successful edit records an edit timestamp and returns a new opaque
  revision.
- Saving must include the revision that was read. A stale revision is rejected
  with a conflict result; it must never overwrite a newer edit silently.
- Local and HTTP Journal Providers expose the same behavior.

## Automatic speech routing

- Explicit context and agent prefixes remain authoritative.
- Unmatched speech is classified by an OpenClaw model run with tools and
  delivery disabled. The only valid outcomes are `record_only` and
  `task_candidate`.
- `record_only` is appended immediately with no route dialog.
- `task_candidate` opens the existing choice between recording and sending to
  OpenClaw. Classification never creates a Session.
- Timeout, unavailable classifier, invalid output, or uncertainty falls back
  to `record_only`.
- Sending to OpenClaw still requires an explicit user action.

## Petdex import

- The first release treats codex-pets.net as a user-selected download source,
  not a catalog API or mirrored asset repository.
- Settings can open codex-pets.net and import a local ZIP or directory.
- Imports are treated as untrusted input and fail closed on path traversal,
  links, special files, excessive size/count/depth, executable content,
  external URLs, MIME spoofing, invalid dimensions, or unsupported formats.
- Supported source data is converted into canonical OpenClaw Pet Pack data,
  then validated by the existing Pet Pack validator.
- Users preview mapped semantic states before activation. Import failure or
  cancellation leaves the active pet unchanged.
- Imported artwork keeps its source license and attribution. Packs without a
  clear redistribution license are local-only and cannot be exported or
  bundled by OpenClaw Pets.
- Field-level Petdex conversion requires a verified real downloaded pack; no
  undocumented field may be guessed.

## Multiple companion computers

- Each installation has its own paired device identity, local active Pet Pack,
  recording state, route dialog, and interaction state.
- Journal observations are shared through the configured Journal Provider.
- Sessions and projected state are correlated to the originating device and
  interaction. A task from one companion cannot animate another companion.
- Different simultaneous Journal writes are preserved. Concurrent edits of
  the same revision return a conflict to the stale client.
- Remote Gateways are supported through authenticated `wss://` connections;
  each desktop is paired independently.

## Confirmed public test seams

1. Journal Provider: read, update, conflict, and read again.
2. Utterance routing: prefix precedence, classifier outcomes, safe fallback,
   and no Session creation before confirmation.
3. Pet import: local ZIP/directory validation, conversion, preview/activation,
   and active-pet preservation on failure.
4. Multi-companion: two device clients share Journal data while interaction
   and animation state remain isolated.
