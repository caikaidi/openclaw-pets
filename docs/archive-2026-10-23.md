# Local source archive — 2026-10-23

This branch preserves the final local OpenClaw Pets source before retiring the
local installation, build caches, desktop application, and application data.

It includes the 12 local commits after the previously published `main` and the
remaining desktop interaction, recording, editing, and Todo changes from the
working tree. Source files shared with the final 2026-09-09 acceptance delivery
were compared byte for byte and matched at archival time.

This is a source preservation snapshot, not a newly tested release. No new build
or runtime acceptance run was performed for this archive. Existing tests and
build instructions remain in the repository; consult `README.md`,
`CONTRIBUTING.md`, and `docs/installation.md` before restoring it on a newer
OpenClaw version.

Restore the source with:

```sh
git clone --branch archive/local-retirement-2026-10-23 \
  https://github.com/caikaidi/openclaw-pets.git
```

Dependencies, Rust target directories, compiled applications, local credentials,
private pet assets, and personal activity data are deliberately excluded.
Recreate local connection settings and install dependencies when restoring.
